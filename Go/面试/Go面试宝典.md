1、程序执行前包初始化时（只会初始化一次）
2、package依赖顺序为：main -> A -> B -> C
   执行顺序为：C -> B -> A -> main

## go语言中new和make关键字的区别？
1、make不仅会分配内存空间而且还会对内存进行初始化（不为nil）
2、make返回的是类型本身（T）;new返回的是指向类型的指针（*T）
3、make只能为slice、map、channel类型进行分配及初始化内存空间，new 可以为任意类型

# go runtime
## GC
内存管理，对不再引用的对象进行垃圾回收

### 标记清除法
步骤：
1、暂停业务程序（STW）
2、标记可达和不可达的对象
3、清除不可达对象
4、解除暂停

缺陷：
1、暂停整个业务程序（出现卡顿）
2、扫描整个堆，代价很大
3、产生内存碎片

### 三色标记法
1、新创建的对象标记为白色
2、从根节点遍历所有对象，标记为灰色
3、遍历灰色对象集合，将灰色引用的白色对象放大灰色集合中，同时将此灰色对象放到黑色对象集合中
4、重复上述步骤，直到所有的灰色对象都被标记（此时，内存中只有黑白两种颜色）
5、回收白色集合中的对象

### 屏障机制
#### 强三色不变式
不允许黑色直接或间接引用白色对象

#### 弱三色不变式
允许黑色引用白色对象，但有一个前提：这个白色对象必须存咋其他灰色对象引用
灰色对象用来保护该白色对象，使其不被垃圾回收

满足两个不变式之一，可以保证对象不丢失。
